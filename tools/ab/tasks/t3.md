## Request (verbatim)

```text
Add a Settings > Configuration page that holds the default permission level for new sessions (Ask for approval, Approve for me, Full access), with a plain explanation of what each level really allows in Brigadier and its risks; check the real sandbox for that, don't guess. A new session starts at that default unless I pick another level for it; a session that already exists keeps its own level. ```
```
